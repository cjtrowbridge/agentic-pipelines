# Playbook: Review Post-Run Analysis

## Use when
Reviewing failure cohorts, performance reports, or remediation proposals after a run.

## Load
Human-readable run narrative, machine report, deterministic trajectory/cohort metrics, representative rejected candidates and redacted thread references, evaluation metrics, authority reference, run-evidence reference, and remediation schema.

## Procedure
1. Verify counts and deterministic metrics independently of model prose.
2. Check cohort membership and representative selection.
3. Separate observations, calculations, hypotheses, unknowns, and recommendations.
4. Compare first attempts with accepted or terminal trajectories. Assess input, prompt, context, schema, normalizer, validator authority, semantic review, provider, orchestration, or infeasible goal.
5. Identify repeated feedback, non-progress, prompt growth, exact work sent to inference, and suspected false deterministic rejection.
6. Require evidence, expected benefit, regression risk, fixture, and safe sample scope for any proposed change. Reject one-off prompt accretion when a generalized correction belongs elsewhere.
7. Accept, revise, defer, reject, or record no change; analysis cannot execute it.

## Output
A reviewed advisory disposition with evidence, risks, required approvals, and next action.
