# Playbook: Audit Existing Pipeline Conformance

## Use when
Reviewing a host after governance changes or when run evidence suggests misassigned authority, fragmented semantics, or retry friction.

## Load
The host stage graph, semantic-unit/example/session declarations, prompts, validators, schemas, review/repair/promotion rules, representative reports, rejected candidates, thread evidence, tests, and authority/run-evidence references. Do not load unrelated entity content.

## Procedure
1. Record revisions, ownership, scope, and evidence gaps. Do not mutate host files.
2. Inventory transformations, gates, derivatives, reviews, repairs, and escalations. Classify exact validation, safe normalization, routing heuristic, bounded semantic judgment, human decision, or ambiguous/misassigned authority.
3. For each gate record actual property, claimed verdict, authority, proof, proxy representation, false-rejection/acceptance risk, and evidence.
4. Flag semantic laundering, context fragmentation, semantic microstage proliferation, reviewer scope escape, operator-intent demotion, lossy derivatives treated as sources, exact work sent to inference, prompt accretion, retry ratchets, unsafe writes, missing reports, or rejected-evidence leakage.
5. Reconstruct first-to-final trajectories. Compare examples, first output, feedback, later outputs, prompt growth, and terminal outcome. Identify the earliest responsible layer.
6. Distinguish legitimate exact domain rules and risk-justified high-assurance review from ceremonial evidence machinery.
7. Propose the smallest host remediation tied to evidence, benefit, risk, and a fixture. Prefer improving initial examples, prompt, context, schema, or scope before adding stages. Permit no-change and accepted-exception outcomes.

## Output and stop conditions
An evidence-backed conformance report and proposed host plan. The audit remains read-only; implementation requires separate approval. Stop for missing representative evidence, unresolved ownership, credentials, or a material policy decision.
