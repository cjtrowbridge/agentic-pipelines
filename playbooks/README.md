# Playbooks

Do not browse this directory as a prerequisite. Start at `../AGENTS.md`; its task table selects one primary playbook. Framework changes additionally load the planning playbook named by the framework-change route.

Only routed playbooks are active product instructions. Unrouted procedures should be removed or added to the router through an approved framework change.

`how_to_set_up_pipeline_entrypoints_in_vscode.md` owns creation and review of host-owned VS Code tasks, the selected main play action, and their platform-native prerequisite/bootstrap boundary.
